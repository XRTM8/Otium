منظومة Otium التقنية الحرة
للقراءة، والمسح الضوئي، والربط اللحظي المباشر

تطبيقات مفتوحة المصدر لنظامي Windows و Android، مصممة بلغة Rust وأحدث تقنيات الويب، تعمل محلياً بالكامل بدون أي خوادم سحابية، بدون جمع بيانات، وبدون إعلانات.

التطبيقات الرسمية في المنظومة

تطبيقات خفيفة مصممة لتعمل معاً أو بشكل مستقل بدون إعدادات معقدة

Otium Reader

v1.5.0
قارئ المستندات والكتب الإلكترونية عالي الكفاءة

قارئ PDF مبني بمحرك Tauri و Rust المخصص ومكتبة PDF.js. يتميز بفيزياء حركية 120 FPS بدون أي Layout Thrashing، وضع الصفحتين المتطابق للكتب، ومحرك بحث عربي ذكي يتجاوز الهمزات والتشكيل، مع قارئ صوتي محلي (TTS) بدون إنترنت وتخزين IndexedDB محصن ذاتياً.

Rust React 19 PDF.js TTS Engine Windows x64 Android APK
تحميل لويندوز (.exe) تحميل حزمة أندرويد (.apk) المستودع والكود المصدري

Otium Scan

v1.0.3
ماسح المستندات والبطاقات الذكي مع OCR محلي

تطبيق أندرويد لمسح المستندات ضوئياً بكاميرا الهاتف. يتضمن خوارزمية ذكية لكشف حواف الورق والقص وتعديل المنظور، مرشحات تنقية وإزالة الظلال، واستخراج نصوص محلي بالكامل (Offline OCR باللغتين العربية والإنجليزية) لإنشاء مستندات PDF نصية قابلة للبحث، مع خزنة محلية مشفرة برمز PIN.

Android Offline OCR Edge Detection PDF Generator PIN Vault
تحميل OtiumScan.apk المستودع والكود المصدري

Otium Link

v1.5.1
الجسر اللحظي للحافظة ونقل الملفات P2P بدون سحابة

أداة لربط الحاسوب والهاتف عبر شبكة Wi-Fi المحلية لنقل الحافظة ومشاركة الملفات مباشرة (Peer-to-Peer). يعتمد على خادم TCP مباشر مع فحص سلامة البايتات بنظام CRC32، وتطهير تلقائي للروابط من بارامترات التتبع، وجدار ناري يرفض أي اتصال خارج نطاق الشبكة المحلية الخاصة (RFC 1918).

Rust P2P TCP Port 42425 UDP Port 42424 CRC32 Stream URL Cleaner Cross-Platform
تحميل لويندوز وأندرويد المستودع والكود المصدري
Windows Package Manager (Winget) — التثبيت المباشر

# 1. تثبيت قارئ المستندات Otium Reader

winget install XRTM8.OtiumReader


# 2. تثبيت جسر الحافظة والملفات Otium Link

winget install XRTM8.OtiumLink

البناء من المصدر (Build from Source)

المشاريع كلها تعتمد على Node.js و Rust، ويمكنك استنساخ وبناء أي تطبيق محلياً بثلاث خطوات:

# استنساخ المشروع وتثبيت الاعتماديات

git clone https://github.com/XRTM8/Otium.git

cd Otium

npm install


# بناء حزمة الإنتاج لنظام Windows

npm run tauri:build


# أو بناء حزمة أندرويد المستقلة (APK)

npm run tauri:android

المعايير الهندسية لمنظومة Otium

المبادئ التقنية المتبعة في كافة مستودعات المنظومة

01
Local-First (الأولوية للمحلي)

كافة البيانات، المستندات، والنصوص المنسوخة تُعالج وتُخزن في جهاز المستخدم حصراً، بدون أي خوادم وسيطة أو قواعد بيانات خارجية.

02
GPL v3 (برمجيات حرة للأبد)

كود المصدر متاح بالكامل لمراجعته وتعديله وتدقيقه، وتضمن رخصة GNU GPL v3 بقاءه حراً ومجانياً دون أي قيود أو اشتراكات.

03
Zero Telemetry (صفر تتبع)

التطبيقات لا تحتوي على أي حزم تحليلات، ولا معرفات إعلانية، ولا تطلب أي أذونات غير مطلوبة للوظيفة الأساسية.
