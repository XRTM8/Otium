Otium Reader

v1.5.0
قارئ المستندات والكتب الإلكترونية فائق السلاسة

محرك قراءة مخصص مبني بـ Tauri v2 و Rust ومكتبة PDF.js. صُمم لمعالجة ملفات PDF الضخمة بدون أي انهيار، مع استجابة 120 FPS بدون Layout Thrashing، وضع الصفحتين المتطابق للكتب، ومحرك بحث عربي ذكي يتجاهل علامات التشكيل، مع قارئ صوتي محلي (TTS) بدون اتصال وتخزين IndexedDB المحصن.

✓ فيزياء حركية 120 FPS
✓ وضع الصفحتين الحقيقي
✓ نطق صوتي محلي (TTS)
✓ بحث عربي ذكي بلا تشكيل
تحميل لويندوز (x64) تحميل حزمة أندرويد (.apk) كود المصدر على GitHub
winget install XRTM8.OtiumReader

Otium Scan

v1.0.3
ماسح المستندات والبطاقات الذكي مع OCR محلي

تطبيق أندرويد متكامل لمسح المستندات ضوئياً بكاميرا الهاتف. يتضمن خوارزمية كشف الحواف والقص الذكي التلقائي وتصحيح المنظور، مرشحات تنقية وإزالة الظلال، واستخراج نصوص محلي بالكامل (Offline OCR باللغتين العربية والإنجليزية) لإنشاء مستندات PDF نصية قابلة للبحث، مع خزنة محلية مشفرة برمز PIN.

✓ كشف ذكي وتصحيح أطراف الورقة
✓ استخراج نصوص محلي (Offline OCR)
✓ وضع بطاقات الهوية المزدوج
✓ خزنة مستندات مشفرة برمز PIN
تحميل OtiumScan.apk كود المصدر على GitHub
Package: com.otium.scan

Otium Link

v1.5.1
الجسر اللحظي للحافظة ونقل الملفات P2P بدون سحابة

أداة لربط الحاسوب والهاتف عبر شبكة Wi-Fi المحلية لنقل الحافظة ومشاركة الملفات مباشرة بين الأجهزة. يعتمد على خادم TCP مباشر على منفذ 42425 مع فحص سلامة البايتات بنظام CRC32، وتطهير تلقائي للروابط من بارامترات التتبع الإعلانية، وجدار ناري يقبل فقط عناوين الشبكة المحلية الخاصة (RFC 1918).

✓ مزامنة الحافظة الفورية (P2P)
✓ نقل ملفات متدفق مع فحص CRC32
✓ تطهير روابط التتبع التلقائي
✓ نظام تحديثات ثلاثي الطبقات عند الطلب
تحميل لويندوز وأندرويد كود المصدر على GitHub
winget install XRTM8.OtiumLink

المعيار التقني التطبيقات السحابية التقليدية منظومة Otium الحرة
مكان تخزين البيانات خوادم طرف ثالث وقواعد بيانات سحابية محلياً 100% على جهازك الشخصي (Local-First)
نموذج التكلفة والتسعير اشتراكات دورية أو إعلانات وتتبع مجاني بالكامل وحر للأبد تحت رخصة GNU GPL v3
العمل بدون اتصال بالإنترنت يتوقف عن العمل أو يتطلب تسجيل دخول دوري يعمل بكامل وظائفه (OCR, TTS, P2P) بلا إنترنت
جمع البيانات والتحليلات (Telemetry) تتبع مستمر لسلوك القراءة والنشاط صفر تتبع (Zero Telemetry) بدون أي إرسال للبيانات
المحرك البرمجي واستهلاك الذاكرة تطبيقات ثقيلة تستهلك الذاكرة والبطارية محرك Rust فائق السرعة وأدنى استهلاك للذاكرة
Engineering Ethics

المعايير الهندسية والأخلاقية للاستوديو

المبادئ الصارمة المتبعة في تطوير وصيانة كافة مستودعات Otium

1. ملكية البيانات حق أصيل

كتبك ومستنداتك ومسوداتك ونصوص حافظتك تخصك أنت وحدك. لا يُسمح لأي كود في برامجنا بإنشاء اتصالات سحابية غير مصرح بها.

2. برمجيات حرة للأبد (GPL v3)

كل سطر برمجي متاح بشفافية تامة للمجتمع العالمي، مما يحمي المستخدمين من الاحتكار وتغيير سياسات الاستخدام التعسفية.

3. جودة التنفيذ الصارم (Zero Bloat)

التطوير بلغة Rust واستخدام خوارزميات فحص البايتات (CRC32) والتخزين المحصن ذاتياً، لمنع أي تسريب للذاكرة أو انهيار في التطبيقات.
