Otium Reader

v1.5.0

قارئ الكتب والمستندات فائق السلاسة

محرك عرض متقدم لا ينهار، سلاسة فيزياء 120 FPS بدون أي Layout Thrashing، وضع الصفحتين المتطابق، قراءة صوتية ذكية (TTS) دون إنترنت، وحفظ لحظي مشفر محلياً.

  • ✓ استجابة فورية بدون استهلاك الذاكرة
  • ✓ بحث عربي ذكي مجرد من التشكيل والزوائد
  • ✓ دعم ويندوز وأندرويد بتوافقية تامة

Otium Scan

v1.0.3

ماسح المستندات والبطاقات الذكي المحصّن

التقاط ذكي وقص آلي لأطراف الورقة، مرشحات تنقية احترافية للطباعة، استخراج نصوص عربي وإنجليزي دون إنترنت (Offline OCR)، وخزنة مستندات مشفرة برمز PIN.

  • ✓ تصدير مستندات PDF نصية قابلة للبحث
  • ✓ وضع بطاقات الهوية المزدوج (وجه وخلف)
  • ✓ صفر اشتراكات وصفر إعلانات وصفر علامات مائية

Otium Link

v1.5.1

الجسر اللحظي للحافظة والملفات P2P

تبادل فوري ومباشر للنصوص والملفات بين حاسوبك وهاتفك عبر Wi-Fi المحلي دون خوادم. تدفق فائق السرعة مع فحص CRC32، وتطهير بارامترات التتبع، ودعم الاتصال المباشر IP.

  • ✓ استكشاف تلقائي مشفر للأجهزة المحلية
  • ✓ درع حماية البيانات الحساسة والبطاقات
  • ✓ نظام تحديثات ثلاثي الطبقات عند الطلب
