Otium Reader

v1.5.0
قارئ مستندات PDF

محرك قراءة فائق السرعة يدعم المستندات الضخمة، عرض الشاشات المزدوجة، أدوات التظليل، وبدون أي اتصال بالإنترنت.

تحميل لويندوز EXE حزمة أندرويد APK المستودع المصدري GPL-3.0

Otium Scan

v1.0.0
ماسح مستندات ذكي

مسح وتصحيح زوايا المستندات الورقية عبر كاميرا الهاتف وتحويلها لملفات PDF نظيفة، دون إرسال صورك لأي خادم.

حزمة أندرويد APK المستودع المصدري GPL-3.0

Otium Link

v1.5.1
جسر الحافظة والملفات

مزامنة النصوص ونقل الملفات الكبيرة فورياً بين ويندوز وأندرويد عبر شبكتك المحلية المباشرة بدون وسيط.
